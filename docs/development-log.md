# Журнал развития Liyaro

## 2026-07-23 — Главная как приглашение к разговору

- Сократили главную и отказались от формата презентации студии.
- Основная задача страницы теперь — помочь человеку написать первое сообщение.
- Вместо перечня услуг добавили короткие примеры живых ситуаций.
- Процесс сократили до трёх понятных шагов после первого обращения.
- Добавили форму, в которой можно описать задачу и выбрать удобный способ ответа.
- Обращения сохраняются в PostgreSQL через модель `Inquiry`.
- Доставку уведомлений в Telegram оставили для отдельной итерации.
